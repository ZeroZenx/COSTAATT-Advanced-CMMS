## 🚀 **Getting Started**

### **Quick Start**
```bash
# Install all dependencies
npm run install:all

# Start database
npm run docker:up

# Setup database with new schema
npm run db:setup

# Start all services
npm run dev:all-mobile
```

### **Access Points**
- **Web App**: http://localhost:5174
- **API**: http://localhost:4000
- **Mobile App**: Expo Go app
- **phpMyAdmin**: http://localhost:8081
